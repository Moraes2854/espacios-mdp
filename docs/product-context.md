# Contexto de producto

## Posicionamiento

Espacios profesionales y consultorios por hora en Mar del Plata.

No debe comunicarse como un servicio exclusivo para psicólogos. La propuesta está abierta a cualquier profesional o persona que necesite un espacio privado, cómodo y equipado para atender, reunirse o trabajar por hora.

## Públicos posibles

- Psicólogos
- Nutricionistas
- Coaches
- Consultores
- Asesores
- Docentes particulares
- Profesionales independientes
- Profesionales de estética no invasiva
- Personas que necesiten una sala privada para reuniones, entrevistas o sesiones

## Precios iniciales de referencia

- Hora suelta: $6.000
- Uso recurrente desde 4 horas semanales: $5.000/h
- Packs intensivos: a consultar

## Condiciones comerciales iniciales

- Pago por adelantado
- Limpieza incluida
- Servicios incluidos
- Wifi incluido
- Acceso digital
- Reserva sujeta a disponibilidad

## Funcionalidades web deseadas

- Hero principal con propuesta clara
- Beneficios
- Usos posibles
- Cards de espacios/consultorios
- Tabla de precios
- Cómo funciona
- Calendario visual de disponibilidad
- CTA por WhatsApp
- FAQ
- Ubicación aproximada en Mar del Plata
- Footer con contacto

## Roadmap funcional

### MVP

- Landing con SEO local
- Consulta por WhatsApp
- API de espacios
- API de solicitudes de reserva
- Base PostgreSQL

### Versión 2

- Panel administrador
- Confirmación/rechazo de reservas
- Integración con Google Calendar
- Estados de reserva: disponible, ocupado, reservado fijo, pendiente

### Versión 3

- Pagos online
- Bloqueo automático de horarios
- Acceso digital integrado
- Automatización de instrucciones de ingreso
